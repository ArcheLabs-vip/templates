# Start — Coleção Essencial — Contabilidade

Aplicação da Coleção Essencial otimizada para escritórios contábeis e contadores. Prioriza a apresentação de serviços como BPO Financeiro e Gestão Tributária, diferenciais do escritório, prova de confiança (depoimentos) e solicitação de diagnóstico.

Derivado do `@arche-labs/start-essencial-core`.

## Comandos

```bash
npm install
npm run dev
npm run build
```
